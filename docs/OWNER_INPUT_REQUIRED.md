| Item | Current Working Default | Owner Input Needed |
| :--- | :--- | :--- |
| **Exact Item Prices** | Benchmarked Mukalla pizza rates (Margherita: 3,500 / 5,500 / 7,500 YER; Pepperoni: 4,500 / 7,000 / 9,500 YER). | Official printed menu / price sheet with any recent inflation updates. |
| **Active Bank & Wallet Accounts** | Kuraimi (`PH-772207788`), Al-Amqi (`25401982`), Al-Busairi (`889104`). | Exact official recipient account numbers and names displayed to customers. |
| **Kitchen Oven Capacity** | 8 orders per 15-minute slot. | Maximum number of pizzas the kitchen oven deck can bake simultaneously during peak rush. |
| **Preparation Duration per Category** | Pizzas: 15–20 minutes; Pastries (Fatayer): 10–12 minutes; Sides: 8 minutes. | Confirmed prep times under normal and busy kitchen shifts. |
| **Current Counter POS** | Handled as a self-contained digital ordering layer. | Name of software (if any) currently running at the cash register (e.g. Al-Ameen, Onyx Pro, etc.) for future direct API sync. |
| **Delivery Policies (Phase 4)** | Disabled in MVP (Pickup-first). | In-house delivery riders available, or preference to partner with local logistics. |
